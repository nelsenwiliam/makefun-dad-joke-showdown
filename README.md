One dad joke, written by a program for make.fun's "Dad Joke Showdown" bounty ($5 in USDC). The program writes a single 120-character dad joke to `/output/entry.txt` — pure Python stdlib, deterministic, no network, no randomness.

> Our Wi-Fi went down, so I told my son we'd have to talk to each other tonight. He asked, 'What's the password for that?'

## Run it

```sh
python3 main.py
```
